# Moonlight Tizen v4.0.6

## What's new

- The library follows the remote by rows: up and down change row, left and right stay
  in the row.
- Two quick mouse clicks now select two diagnosis history records.
- After clicking a library control with the pointer, the arrows and OK start from it.

## Downloads

- **Normal:** standard build.
- **ForceGM:** same features, with a request to enable TV panel Game Mode.

## Installation

Download one of the `.wgt` files below and follow the
[visual installation guide](https://samirmartins.github.io/vibelight-tizen/#install)
or the [Installation Guide](https://github.com/samirmartins/vibelight-tizen/blob/master/INSTALLATION.md).
